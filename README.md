# RODEO II Core Code

William Jenkins, Ph.D.  
Scripps Institution of Oceanography  
University of California San Diego  

## Overview

This repository contains core code for the Real-Time Opportunity for Development Environmental Observations (RODEO) II project, which is focused on detecting and analyzing pile driving pulses in underwater acoustic data collected during wind farm construction offshore of New England.
The code is designed to work with data collected from various stations, and it includes scripts for inventorying data files, detecting pile driving events, and computing soundscape metrics.

The code is provided as a Python package.
Application of the code is found in accompanying repositories:
- (🔒 private) [RODEO II Construction Soundscape](https://github.com/NeptuneProjects/RODEO-II_Construction-Soundscape)
- [Vineyard Wind](https://github.com/NeptuneProjects/RODEO-II_VineyardWind)

## Installation

The package can be installed using `pip`:
```bash
pip install git+https://github.com/NeptuneProjects/RODEO-II.git
```
